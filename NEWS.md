# repli 0.1.0

## Initial release

* Added replicate-based imputation for Missing At Random (MAR) values
  in proteomics data.
* Added support for imputation of data frames and
  `SummarizedExperiment` objects.
* Added mixed MAR/MNAR imputation using replicate-based imputation
  for MAR values and user-specified methods for MNAR values.
